Task index¶

Every command this repo publishes, with what it does. inv --list prints the same thing on a machine that already has PULSE installed; this page is for the rest of the time — deciding whether something exists before you clone, or finding the name of the task you half-remember.

The table is generated from the invoke namespace by inv catalog.render-tasks and guarded by a unit test, so a task cannot be added, renamed or re-described without this page following. Each row’s text is the first sentence of the task’s own docstring; inv --help <task> prints the whole thing, including its options.

How to read the names. inv <namespace>.<task> reads as an imperative: the namespace is the subject, the task is the action — inv apt.install-base is “apt: install base”. A few namespaces are themselves the action (setup, verify, clean, deploy, test), so their leaves name a scope instead: verify.all, test.unit. Names like status, check, list and diff never modify anything.

Not every task is meant for everyday use. The ones a normal machine actually needs are in index.md’s quick start and maintenance sections; the rest exist for a specific situation — a corporate proxy, a WSL distro, a container build, a docs edit.

Warning

Tasks that write to a live GNOME session (gnome.configure, gnome.install-extensions, screenshot.enable/disable) need a real Wayland/X11 session and change your desktop immediately. Their read-only siblings (gnome.status, screenshot.status) are safe anywhere, and PULSE_DRY_RUN=1 turns any task into a report of what it would do.
